Mission 1 — Know your computer

## 2. Task / objective

Explain input, processing, output and storage using IPOS, identify hardware and software, and list three computer-based systems used in everyday life.

## 3. Work completed

### Task 1.1 — Trace one activity using IPOS

I chose **typing and saving a document**.

| Stage | What happens in this example | Hardware or component |
|---|---|---|
| Input | I type words in a document, and the keyboard sends each key press to the application. | Keyboard |
| Processing | The CPU carries out the editor's instructions, and RAM holds the document while it is open. | CPU and memory |
| Output | The document appears on the screen as I add or edit text. | Monitor or screen |
| Storage | When I save the document, the application writes it to the computer's persistent storage. | SSD or hard disk |

Extra steps: after saving, the file remains on the disk, and I can reopen it later. I could also copy it to cloud storage as a backup.

## 5. My understanding

IPOS shows how a computer turns actions into useful information. Input starts the process, the processor and memory work on it, output displays the result, and storage keeps information for later use. Hardware is the physical equipment, while software gives the equipment instructions. Everyday devices also contain computers even when they do not look like laptops.
